## 八、链接失效说明

- App 类链接以各商店为准；若地区不可用，用官网或 GitHub 替代。  
- 大厂功能常需登录、付费或企业许可（如 Copilot in Planner）。  
- GitHub 仓库以 `main` 分支路径为准，若 404 请打开仓库根目录自行浏览。
