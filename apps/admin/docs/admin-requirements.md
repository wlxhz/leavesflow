# LeavesFlow 后台一期需求文档

版本日期：2026-05-28

文档用途：面向产品范围、功能扩展和验收。后续讨论“后台要做什么、扩展什么功能”时看本文档。

技术实现、接口、表结构、部署和维护请看：

```text
apps/admin/docs/admin-technical-spec.md
```

## 1. 一期定位

后台一期是一个单页基础反馈面板，不是完整运营后台。

核心目标：

```text
让管理者快速看清 LeavesFlow 当前的用户清单、用户变化、模型资源使用和基础业务情况。
```

一期只做必要的查看和少量用户数据清理能力，不做多角色权限和复杂运营流程。

## 2. 已确认决策

```text
页面形态：单页 Dashboard
访问保护：简单访问密码
上线位置：https://leavesflow.syt.huickathon.cn/admin
最近列表：默认展示 10 条
打卡文本：一期不展示用户填写的“完成了什么、产出了什么、遇到了什么问题”
```

## 3. 一期重点关注

后台一期重点关注：

- 应用现有用户清单。
- 1 天、7 天、30 天内用户数据变化。
- 1 天、7 天、30 天内模型资源使用情况。
- 模型资源使用量以 token 消耗量呈现，单位为 K。
- 定向查询某个用户的资源使用情况。
- 删除某个用户的注册数据。

## 4. 当前能力结论

已确认当前代码中没有以下能力：

- 没有后台管理页面。
- 没有 `/api/v1/admin/*` 后台接口。
- 没有后台用户查询接口。
- 没有后台删除用户注册数据接口。
- 没有按用户统计模型 token 消耗的表或接口。
- AI 调用目前没有持久化记录 token usage。

因此一期开发需要补齐后台页面、后台接口、模型 token 用量记录、用户定向查询和用户删除能力。

## 5. 页面内容

一期只做一个 Dashboard 单页。

页面区域：

```text
顶部访问密码校验
核心指标区
用户变化区
模型资源使用区
用户清单区
用户定向查询区
用户删除操作区
基础业务状态区
```

## 6. 核心指标区

展示：

```text
总用户数
总目标数
总任务节点数
总打卡数
总能力标签数
```

用途：

- 快速判断当前应用是否有真实业务数据。
- 快速观察路径、任务、打卡和能力标签的大盘规模。

## 7. 用户变化区

展示 1 天、7 天、30 天三个窗口。

每个窗口展示：

```text
新增用户数
用户减少数
净变化数
```

业务含义：

- 新增用户数：窗口期内注册的用户数。
- 用户减少数：窗口期内被后台删除的用户数。
- 净变化数：新增用户数减去用户减少数。

## 8. 模型资源使用区

展示 1 天、7 天、30 天三个窗口。

主要反馈形式：

```text
token 消耗量，单位 K
```

展示指标：

```text
总 token 消耗 K
路径生成 token 消耗 K
能力提炼 token 消耗 K
```

展示规则：

- 使用 `total_tokens / 1000` 得到 K。
- 建议保留 1 位小数。
- 历史未记录 token 的调用显示为 `0` 或 `未知`。

## 9. 用户清单区

默认展示 10 条用户。

字段：

```text
用户 ID
用户名
昵称
注册时间
更新时间
目标数
任务数
打卡数
能力标签数
近 1 天 token K
近 7 天 token K
近 30 天 token K
```

不展示：

```text
password_hash
auth_token
```

## 10. 用户定向查询区

至少支持：

```text
按用户 ID 查询
按用户名查询
```

查询结果展示：

```text
用户基础信息
注册时间
更新时间
目标数
任务数
打卡数
能力标签数
近 1 天 token K
近 7 天 token K
近 30 天 token K
全部已记录 token K
最近模型调用记录
```

最近模型调用记录展示：

```text
调用时间
调用类型
模型
token K
状态
```

## 11. 用户删除操作区

一期需要支持删除某个用户的注册数据。

交互要求：

- 删除入口放在用户定向查询结果中。
- 删除前必须二次确认。
- 二次确认需要输入用户名或用户 ID。
- 删除后需要刷新 Dashboard 数据。

删除操作需要记录：

```text
删除的用户 ID
删除的用户名
删除时间
删除前关联目标数
删除前关联任务数
删除前关联打卡数
删除前关联能力标签数
```

待确认：

```text
删除用户时采用硬删除还是软删除。
```

建议：

- 如果当前主要是内部测试和清理测试账号，选硬删除。
- 如果已经有真实用户数据，选软删除。

## 12. 打卡文本展示边界

已确认一期不展示用户填写的三段打卡文本：

```text
完成了什么
产出了什么
遇到了什么问题
```

Dashboard 中打卡相关信息只展示：

```text
最近打卡用户
所属路径
所属任务
打卡时间
```

## 13. 一期不包含

一期不做：

```text
多层用户权限
多角色 RBAC
运营、客服、财务等角色区分
用户禁用/启用
用户密码重置
用户资料编辑
标签和 Prompt 编辑
数据导出
复杂审计日志
费用核算
API 请求日志统计
日活/月活精确统计
Android 设备和版本统计
```

## 14. 验收标准

一期完成后应满足：

1. 可以通过 `https://leavesflow.syt.huickathon.cn/admin` 打开后台单页。
2. 后台入口有简单访问密码保护。
3. 可以看到当前用户清单，默认 10 条。
4. 可以看到 1 天、7 天、30 天内用户新增、减少和净变化。
5. 可以看到 1 天、7 天、30 天内模型 token 消耗，单位 K。
6. 可以定向查询某个用户的资源使用情况。
7. 可以删除某个用户的注册数据，删除前必须二次确认。
8. 删除动作会被记录，用于统计用户减少数。
9. 不展示用户打卡三段文本。
10. 不展示 `password_hash`、`auth_token`、AI API Key。
